  راهنمای ساخت نرم‌افزار ویندوزی (فایل .exe)
  Smart ID Finder v6
═══════════════════════════════════════════════════════════

پیش‌نیاز روی سیستم ویندوز:
  • ویندوز 10 یا 11
  • پایتون 3.10 یا 3.12 (ترجیحاً 3.12)
    دانلود: https://www.python.org/downloads/
    هنگام نصب حتماً تیک «Add Python to PATH» را بزنید.

───────────────────────────────────────────────────────────
روش ۱ — ساده (پیشنهادی)
───────────────────────────────────────────────────────────

1. فایل‌های زیر را در یک پوشه قرار دهید:
     Smart_ID_Finder_v6.py
     build_exe.bat
     requirements.txt

2. روی build_exe.bat دوبار کلیک کنید.

3. صبر کنید تا پیام «تمام شد» بیاید (۲ تا ۵ دقیقه).

4. فایل نهایی:
     dist\Smart_ID_Finder_v6.exe

5. این exe را می‌توانید به هر کامپیوتر ویندوزی کپی کنید.
   روی سیستم مقصد نیازی به نصب پایتون نیست.

───────────────────────────────────────────────────────────
روش ۲ — دستی (اگر bat کار نکرد)
───────────────────────────────────────────────────────────

در Command Prompt یا PowerShell:

  cd مسیر\پوشه\پروژه

  pip install -r requirements.txt

  pyinstaller --noconfirm --onefile --windowed --name "Smart_ID_Finder_v6" --clean --collect-all PyQt5 Smart_ID_Finder_v6.py

فایل exe در پوشه dist ساخته می‌شود.

───────────────────────────────────────────────────────────
نکات مهم
───────────────────────────────────────────────────────────

• اگر آنتی‌ویروس فایل را مشکوک اعلام کرد:
  - طبیعی است؛ فایل‌های PyInstaller گاهی هشدار می‌دهند.
  - آن را به استثناها اضافه کنید یا روی سیستم خود بسازید.

• اگر خطای «Failed to execute script» دیدید:
  - با --console بسازید تا پیام خطا را ببینید:
    pyinstaller --noconfirm --onefile --console --name "Smart_ID_Finder_v6" --collect-all PyQt5 Smart_ID_Finder_v6.py

• حجم فایل حدود ۴۰ تا ۸۰ مگابایت است (چون PyQt5 داخل آن است).

• برای آیکون سفارشی (اختیاری):
  یک فایل icon.ico بسازید و این گزینه را اضافه کنید:
    --icon=icon.ico

───────────────────────────────────────────────────────────
مشکل شبکه شرکت
───────────────────────────────────────────────────────────

اگر pip به اینترنت دسترسی ندارد:
  1. روی سیستم خانگی با اینترنت requirements را نصب و exe بسازید.
  2. فقط فایل .exe را به شرکت منتقل کنید.

یا از mirror داخلی استفاده کنید (اگر دارید).
